# Default illustration credits

The SVG files in this folder are from **Twemoji**, downloaded once at build
time and committed here so the app never fetches anything at runtime
(non-negotiable rule 2).

- Source: https://github.com/jdecked/twemoji (the `assets/svg` folder)
- Graphics license: **CC-BY 4.0** — https://creativecommons.org/licenses/by/4.0/
- Copyright 2020 Twitter, Inc and other contributors
- Downloaded: 2026-09-21

Attribution is required by the license. It is recorded here rather than on a
child screen, which carries no text for the child by design (rule 4).

These are the fallback pictures only. A parent photo for a letter always wins
(SPEC 3.2), which is the whole point of the Family Book.

## Words with no illustration

These five keep the dashed placeholder, because no icon in the set reads
clearly as the word for a two-year-old: **igloo, jam, jug, quilt, zip**.
Letter J has no default picture at all as a result.
