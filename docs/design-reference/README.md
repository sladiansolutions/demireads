# Design reference

These files are the mockup screens exported from the design canvas. They are **visual reference only**, not code to reuse. They use a canvas-specific template syntax (`<x-dc>`, `<sc-for>`, `{{holes}}`) and a missing `support.js`, so they will not run on their own.

Use them for layout, sizes, colors, type, and copy. Rebuild each screen as React components following CLAUDE.md.

| File | Screen |
|---|---|
| Main.dc.html | Home |
| LetterGarden.dc.html | Letter Garden |
| FamilyBook.dc.html | Family Alphabet Book |
| CountDucks.dc.html | Count the Ducks |
| AlphabetSong.dc.html | A to Z Song |
| Goodnight.dc.html | Goodnight |
| ParentArea.dc.html | Parent area |
| LetterWall.dc.html | All 26 letters (parent) |

All screens are designed at 1180 x 820 CSS px, landscape.
